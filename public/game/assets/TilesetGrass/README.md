# TilesetGrass Runtime Asset

Source: `https://beast-pixels.itch.io/overworld-tileset-grass-biome`

Author: Beast Pixels

License: CC0 / Public Domain according to the source page. Attribution is not required by CC0, but the source is recorded here for traceability.

Downloaded archive: `TilesetGrass.zip`

Runtime file:

- `overworld_tileset_grass.png`: 192 x 336 pixel tileset image using 16 x 16 pixel tiles (12 columns, 21 rows, 252 tiles).

Source-only files remain under `assets/TilesetGrass` and are intentionally not copied into `public`:

- `grass_biome.tsx`: Tiled tileset metadata and terrain definitions.
- `map1.tmx`, `map2.tmx`: Tiled example maps.
- `map1.png`, `map2.png`, `preview.png`: rendered examples and preview material.
- `overworld_tileset_grass.ase`, `palette.ase`: Aseprite source files.

The original files under `assets/TilesetGrass` must remain unchanged for provenance and future conversion work.
