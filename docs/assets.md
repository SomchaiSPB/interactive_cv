# Game Assets

## TilesetGrass Audit

`assets/TilesetGrass` is a user-provided downloaded tileset pack. The source files are preserved unchanged.

### Format

- Tile size: 16 x 16 pixels.
- Tileset image: `overworld_tileset_grass.png`, 192 x 336 pixels.
- Grid: 12 columns by 21 rows, 252 tiles.
- Transparency: RGBA PNG.
- `grass_biome.tsx` is an external Tiled tileset XML file. It defines terrain metadata for grass, water, forest, swamp grass, and swamp tiles.
- `map1.tmx` is a 21 x 42 orthogonal Tiled map with two CSV-encoded tile layers.
- `map2.tmx` is a 15 x 15 orthogonal Tiled map with two CSV-encoded tile layers.
- Both TMX files reference `grass_biome.tsx` and can be used as layout/tile-index references.

### Runtime Preparation

The TilesetGrass PNG is copied to `public/game/assets/TilesetGrass/` and is now used by the Phaser prototype as local-only terrain art.

The downloaded archive name was `TilesetGrass.zip`.

Tile-index inspection is documented in `docs/assets/tilesetgrass-contact-sheet.png`, generated by `scripts/generate-tileset-contact-sheet.mjs`.

The current Phaser scene does not load TMX or TSX XML directly, so those files remain reference material rather than browser runtime dependencies.

Before map integration, choose one narrow path:

1. Export a project-owned map from Tiled as JSON and load it through Phaser's Tiled JSON support.
2. Keep the map code-defined and use audited tile indices from the TSX/TMX files.

Do not add a conversion pipeline until the intended map composition is agreed.

### Prototype Use

The tileset is integrated only as a prototype terrain pass for local development. Buildings, quest content, and gameplay logic still use the generated map system.

### Object Mappings

The current multi-tile prototype mappings are:

- `townSquarePlaza`: `17,18,19 / 29,30,31 / 41,42,43` at scale `4`
- `treeCluster`: `57,58,59 / 69,70,71 / 81,82,83 / 93,94,95 / 105,106,107` at scale `2`
- `bushCluster`: `104,105 / 106,107` at scale `2`
- `commandHallFort`: `144,145,146,147,148,149 / 156,157,158,159,160,161 / 168,169,170,171,172,173 / 180,181,182,183,184,185` at scale `2`

The plaza and forest objects are drawn into the prototype terrain layer. The `commandHallFort` object is used as a safe landmark replacement for the `Command Hall` checkpoint only; all other checkpoint buildings still fall back to the generated sprite system.
